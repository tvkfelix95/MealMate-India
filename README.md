# MealMate India

MealMate India is a planned personalised Indian meal planning and cooking web application for students and working professionals.

## Initial product scope

- South Indian cuisine
- Vegetarian, egg, and non-vegetarian preferences
- Daily and 7-day meal plans
- User-defined food budgets
- Beginner-friendly cooking instructions
- Ingredient quantities and preparation/cooking times
- Estimated nutrition information from verified data sources
- Weekly grocery lists
- English language initially, with Tamil planned for a future phase

## Planned technology

- Frontend: React, TypeScript, and Tailwind CSS
- Backend: Python and FastAPI
- Database: PostgreSQL
- Authentication: Supabase Auth
- Version control: Git and GitHub

## Repository layout

- `frontend/` — browser user interface
- `backend/` — API and application business logic
- `database/` — database documentation and future migrations
- `docs/` — product, architecture, and development documentation

## Current status

The repository currently contains project documentation only. Application code and dependencies have not been added yet.
